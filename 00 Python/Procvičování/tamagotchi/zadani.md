# Tamagotchi

1. Vytvořte funkci krmeni

Krmeni ubere hlad (buď na 0 nebo ubere určité množství)
2. Zakomponujte krmení do programu, pod určitou klávesu (např. k, pokud máte k pro konec, zvolte jinou)


3. Vytvořte funkci hra
Hra přidává hlad a žízeň, odebírá energii a zvířátko co si hraje,
má radost

4. Přidejte funkci spánek
Spánek přidává energii
